# textlint-rule-preset-ai-words-ja

AI が書いた日本語に出てきやすい語と言い回しを見つける [textlint](https://textlint.github.io/) のプリセット。

英語をそのまま直訳したような動詞、日常では使わない硬い名詞、大げさな定型句、技術文書に比喩を持ち込む語を、形態素解析の結果で照合する。表層の文字列ではなく品詞と基本形を見るため、「効く」を 1 件書けば「効きます」「効かない」にも当たり、名詞の「有効」「効率」には当たらない。

[@textlint-ja/textlint-rule-preset-ai-writing](https://github.com/textlint-ja/textlint-rule-preset-ai-writing) が文章の構造 (リストの形、見出しの強調、コロンの使い方) を見るのに対して、こちらは語そのものを見る。同じ箇所で 2 種類の指摘が出ないよう、あちらがすでに拾う誇張表現や「〜することが可能」は入れていない。併用できる。

## インストール

```shell
npm install --save-dev textlint-rule-preset-ai-words-ja
```

## 使い方

`.textlintrc.json` に書く。

```json
{
  "rules": {
    "preset-ai-words-ja": true
  }
}
```

ルールごとに設定するときは、プリセット名の下にルール名を並べる。

```json
{
  "rules": {
    "preset-ai-words-ja": {
      "no-ai-words": {
        "allows": ["経路", "/検査|部品/"]
      },
      "no-short-topic-comma": {
        "maxLength": 3
      }
    }
  }
}
```

指摘のルール ID は `ai-words-ja/no-ai-words` の形で出る。`severity` を下げたいときも同じ書き方で指定する。

```json
{
  "rules": {
    "preset-ai-words-ja": {
      "no-ai-words": { "severity": "warning" }
    }
  }
}
```

## ルール

### `no-ai-words`

辞書に載せた語と言い回しを指摘する。

| オプション | 型 | 既定値 | 説明 |
| --- | --- | --- | --- |
| `allows` | `string[]` | `[]` | 指摘しない語。スラッシュで囲めば正規表現になる。当たった箇所の文字列と照合する |

自分が普通に使う語まで指摘されるときは、ルールごと切らず `allows` へ足す。

### `no-short-topic-comma`

主題を短く示しただけで打つ読点を指摘する。

```
議事録は、溜めても資産になりません。
```

長い条件節の切れ目に打つ読点 (「Client Secret を安全に保管できない Public Client の場合は、」) は対象にしない。読点がそこで仕事をしているため、文頭からの文字数で切り分けている。

| オプション | 型 | 既定値 | 説明 |
| --- | --- | --- | --- |
| `maxLength` | `number` | `5` | 文頭から読点までが何文字以内なら指摘するか |

## 辞書に語を足すには

辞書は `src/dictionary.ts` にある。[morpheme-match](https://azu.github.io/morpheme-match/) の Token 列で書き、品詞と基本形で照合する。語を足すときは 5 つに気をつける。

- **分かち書きを先に確かめる。** [Token ビューア](https://azu.github.io/morpheme-match/)に入れて、どう割れるかを見る。「無差別」は `無[接頭詞] + 差別[名詞]` に割れるので 2 トークンで書く。
- **自分の文章での出現数を数えてから入れる。** 自分がすでに使っている語を入れると、警告だらけになって preset ごと切ることになる。
- **複数トークンに割れる語をパターンの先頭に置かない。** マッチャは途中で外れたときに現在のトークンを先頭から試し直さないため、当たらないことがある。
- **前後の語で分かち書きが変わる語は入れない。** たとえば「当たり外れ」は単体では `当たり[名詞] + 外れ[名詞]` だが、「たびに当たり外れが」では `に当たり[助詞]` に融合する。
- **汎用的な名詞は入れない。** スクリーンショットの意味で「絵」を禁止しようとすると、「お絵かき」「絵馬」のような本来の意味での使用に当たる。

別義での発火が多い語は、格助詞を条件に足して切り出せることがある。「落ちる」は単独だと「品質が落ちる」に当たるため、格助詞の「に」を前に置いてフォールバックの意味だけを拾っている。

`test/no-ai-words.test.ts` に「検出したい例」と「検出してはいけない例」がある。語を足したらどちらにも足す。
